# Citrus World v0.1.0

> Historical record from before C006: command paths and measurements below retain their original context. For current commands, use `CITRUS_WORLD/` as the application working directory and `documentation/` in place of `docs/`. See [C006 migration](../coordination/C006-structure.md).

First playable browser release of Babylon Lite Astra Blender Demo.

[Play Citrus World](https://samuelasherrivello.github.io/babylon-lite-astra-blender-demo/).

- Explore a Blender-authored floating village with a pink cottage, mint tower, stream, bridge and orange character.
- Walk with WASD or the thumb joystick, with collision clearance and Idle/Walk animation.
- Drag to orbit the fixed world center; mouse wheel zoom stays within bounds.
- Portrait framing fits desktop and mobile viewports, with a simplified Citrus World interface and a soft panoramic sky.
- WebGPU is preferred with WebGL fallback. No installation or wallet connection is required.

Verification: 14 automated tests, TypeScript/production build, actual Chrome and Edge gameplay/touch-emulation checks at desktop, portrait, narrow and landscape sizes. Browser QA uses a disposable context and leaves caller viewport/API state unchanged, including a tested native-viewport failure case. Physical phone testing is not claimed.

The static release archive must be served over HTTP(S). It is also deployed through the repository's GitHub Pages workflow. To roll back, deploy a previous verified source commit using an additive release; do not rewrite history or overwrite an existing release tag.
