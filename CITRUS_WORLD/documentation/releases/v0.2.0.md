# Citrus World v0.2.0

[Play Citrus World](https://samuelasherrivello.github.io/babylon-lite-astra-blender-demo/).

- Water detail loops along the horizontal river and downward on both waterfalls, with scene reflections, gentle foliage motion and chimney smoke.
- The initial UI loads its styles before the game script, preventing unstyled controls and layout pop-in.
- Losing focus shows a subtle centered Sleeping prompt over a dark fade. Rendering, simulation and reflections stop; returning resumes smoothly with cleared input. Resizing while asleep preserves the frozen image until wake-up.
- Hidden waterfall reflections stay cached, reducing draw calls in the initial view from 354 to 287. Existing camera framing and game assets are retained.
- The application, assets, tools and documentation now live together in `CITRUS_WORLD/`; canonical OpenSpec planning lives in `.openspec/`.

## Verification

Unit, lifecycle, tooling, TypeScript and production build checks pass. Dedicated installed Chrome and Edge sessions cover WebGPU and WebGL, complete water loops, movement/camera controls, responsive layouts, startup stability, sleeping, wake-up and reduced motion. Sleep checks confirm zero render callbacks and unchanged game state while unfocused; scene assets stay in memory for quick resumption. Physical-phone performance is not claimed.

The recorded Chrome timing samples reached approximately 60 fps at a 1280x960 viewport on this machine. Performance depends on hardware and load; the detailed verification report retains outliers and testing conditions. The existing large-bundle build advisory remains.

C007's completed specifications are synced and archived. The production build excludes development/QA diagnostics. No new runtime dependency, navigation migration or asset rebuild is required by the water and sleep changes.
